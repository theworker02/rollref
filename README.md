# rollref

Roll timestamps and ref durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/rollref/

## Install / run

```bash
git clone https://github.com/theworker02/rollref.git
cd rollref
node src/cli.js
node --test
```
